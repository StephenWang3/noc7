# 完结工单报告定位与已结单效果口径

日期：2026-11-02。状态：已采纳。依据：用户确认“完结工单的完整故障报告生成”，并同意优先关注结单工单、复用已保存回答，不重新调用模型、不改提取逻辑。

## 决策

主场景统一为读取已结单工单完整导出材料，形成标准公司故障报告及可追溯的核对报告。完整描述的是材料使用范围和报告结构，不承诺七栏均有确定值、所有附件齐备或报告已经人工批准。人工审核在 NOC 工作台完成，责任方／地点只提供待确认建议。

效果主分母固定为详情已结单工单，拒绝单保留分母；其他状态单列兼容表现。正式填出、未填／冲突、报告交付、建议覆盖及已知语义错误分别陈述。含结案结论的完整输入不用于声称独立准确率。

## 取舍与实现边界

采用文档与页面文案统一、保存结果专项统计。没有扩成阶段报告产品线，没有增加状态硬拦截，没有修改提取器、Schema、约束或报告生成逻辑。现存 `stage`／`closure` 以及其他状态示例属于兼容和反例验证，本轮不迁移旧报告标题或重生成示例。

不采用为提高填出率重新请求模型或现场修复规则的做法：那会改变本轮观察对象，无法回答当前保存回答在已结单工单上的表现。空值调查暴露的时区、格式、模型选择与结构关系问题记录为缺口，后续实现须另有任务范围，不能在统计中暗改答案。
