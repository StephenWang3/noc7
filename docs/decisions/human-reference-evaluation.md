# 人工结论分层参考与截止前评估

状态：已采纳。依据：用户批准“正式报告＋人工结案结论，分层统计”；用户要求 NOC 只读、真实材料不进仓库，且提取器不能看到参考答案。

## 方案与选择

仅正式报告来源集中，但覆盖少；报告与明确人工结案结论分层可兼顾覆盖与溯源；所有原因字段都纳入会混入排查意见。选择第二种，区分正式报告、人工结案说明、邮件最终结论，同时记录作者、审核情况和原文锚点。NOC 保存的自动生成记录不自动获得人工参考资格，创建者与审核者不是同一语义。

首轮采用本地、确定性评估。模型整体裁判便于处理改写，但会引入裁判偏差与接口依赖；逐字全文比较过于严格。选择冻结的原子要点和同义词、时间语义与偏移、过程动作顺序；未命中而不能明确否定的文本留待判定。否定只认紧贴要点的词，要点之后和逗号后同一小句里的否定记为待判定，不把前缀里的「无」「排除」整段否决。只有日期的参考按工单默认时区折到当地日期，时区不能确定则待判定。标注代理做原文转录核对，不声称拥有业务审核资格，也不看结果后补同义词。

## 输入边界

评估模块独立于共享 schema 和提取规则，复用 `EvidenceAnchor`、`GoldTime`、`KeyPoint`、本地解析器、`load_bundle()` 与 `analyze()`。没有引入另一套生产七要素结构，也没有修改现有合成 gold。

首次明确结案动作作为截止，包含销障、结单签收、回访结单、本地关单和结单归档，取最早一条的时间，该条及不早于它的日志不进入输入。最终快照字段缺乏历史版本时默认删除，只接受可与截止前日志核对的字段。标题、真实编号、状态和关联单也移除，避免元数据夹带结论。参考锚点、报告标记、长引文副本、AI 摘要和原始响应留档隔离；邮件和附件必须有唯一、截止前的日志归属，且能完整检查，否则排除。重新登记文件、引用和哈希，提取器只读取独立输入目录。

以上保守边界、二十例／一百条列表的上限、词法副本检查及评分公式，Basis: own judgment。局部措辞检测不等于通用语义防泄漏证明，因此仍需在冻结前核对选入材料与排除记录；不能把自动扫描的通过当作绝对无泄漏证明。保守隔离会减少可评估事实，必须报告这一损失。

## 评分与复现

事实只在参考明确提及、且隔离输入能支持时进入提取效果比较。未标注不等于参考为“未知”；供应商声称不等于确诊。参考之间明确冲突不自行裁定。时间同语义数值冲突自动标记；文本互斥关系和无法自动判断的冲突在冻结标注中记录。

每条来源事实结果为一致、遗漏、明确冲突、待判定、未确认输入支持、参考来源冲突。候选不当结论；结论状态和语义升级可判为冲突。前三类为可判定分母，前三类加待判定为有输入支持的总数。报告一致率与可判定覆盖率，未确认输入支持和参考冲突另列，分母为零使用空值。总数按来源事实计，样本数单列，不重复计算为独立故障。

冻结参考文件、原包清单、隔离包清单和解析证据均绑定哈希。导入结果须来自相同输入和解析证据；新模型只替换提取器，不改变参考。哈希用于一致性检查，不是不可篡改审计系统。运行输出为新建仓库外私有目录，单例失败留本机异常，终端和可提交摘要只白名单计数。

## 边界

本轮评估人工参考一致程度，不衡量真实业务正确率；没有参考覆盖的责任、地点等不能宣布准确。词法同义词不足以判断所有改写；待判定率须与一致率同时阅读。模型接入、修正提取逻辑和全库扫描不在本轮范围。
