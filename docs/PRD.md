# NOC 完结工单完整故障报告生成 PRD

版本：v0.2｜日期：2026-11-02｜状态：按业务定位更新。本文替代 2026-10-27 开发基线草案中的阶段报告、处理中工单主场景和自建人工审核界面规划；历史取舍见 [定位 ADR](decisions/completed-ticket-report-positioning.md)。

## 1. 产品目标

面向 NOC 人员，完成**完结工单的完整故障报告生成**：读取已结单工单已导出的字段、处理记录、邮件、结案说明、RFO 和附件，整理七要素及出处，输出标准化公司故障报告 Word／HTML，以及供核对的 JSON、Markdown／HTML。

“完整”指使用完整导出材料和标准报告结构，不承诺七栏都有确定答案，也不证明源系统全部附件均已导出。工单已结单不等于原因查明、时间无冲突或报告已人工审核。材料缺失、解析限制、含义不清及冲突必须显式列出，不能为填满报告编造结论。

## 2. 用户与流程

1. NOC 人员导入已结单工单标准包，包含已导出的结案材料。
2. 系统解析材料、生成带编号的证据片段，提取七要素并核对出处、时间数值和矛盾。
3. 人员查看七要素、候选、原文出处及待核实项，预览和下载公司报告。
4. 人工审核与修订在 NOC 工作台完成，本课题不实现审核界面，不自动认责、关单、发布或对外发送报告。

演示页支持本地标准包 zip 导入及工作台传工单号。现有代码仍能读取其他状态工单和合成反例，这是兼容与验证能力，不是阶段报告产品线；本次不增加状态硬拦截。

## 3. 当前交付范围

- 解析结构化字段、处理日志、邮件、PNG/JPEG、本地 OCR、PDF、DOCX、EML；未支持、失败或局部待复核材料明确展示。
- 统一 `AnalysisResult`：七要素、候选、事件、出处、材料状态和问题清单；报告只消费校验后的结构，不为 Word 再次提取。
- 公司 Word／HTML 共用报告数据；审核 Markdown／HTML 展示证据与待核实线索，始终保留未经人工审核标识。
- 模型通过配置替换：开发期已授权的 DeepSeek 文本链路；生产内网 Qwen 约 27B 为接入方向，目前只验证兼容协议，未声称内网实调。
- 规则基线与保存响应离线回放用于对照，不代表模型的真实语义能力。

自动同步、生产权限和上线接入取决于正式接口与授权，不能把演示页事件或只读调研当成生产集成。

## 4. 七要素及正式报告边界

| 要素 | 正式输出口径 | 待核实边界 |
| --- | --- | --- |
| 起障时间 | 业务起点、客户报告起点；允许带标签的告警替代时刻 | 不把建单或邮件发送时间直接当起障；告警替代不计算业务故障历时 |
| 恢复时间 | 本次业务实际恢复时刻 | 协议 Up、修复完成、确认动作、关单时间不能直接替代 |
| 现象 | 保留观测方、对象、范围、指标与单位 | 不把局部检查正常当客户整体无故障 |
| 责任方 | 当前自动链路正式栏不填 | 仅 AI 建议，待 NOC 确认，不按设备归属或供应商补定责 |
| 原因 | 明确发生且影响本次业务的故障／机制／作业，自动最高 `documented` | 推测机制、现象、自恢和排查不等于原因 |
| 处理过程 | 带来源的动作、主体、对象和结果 | 流程动作与实际排障区分 |
| 地点 | 当前自动链路正式栏不填 | 仅 AI 建议；端点、告警点、测试节点不能直接当故障点 |

状态分为 `documented`、`confirmed`、`unknown`、`conflicted`。正式填出与正确、可定位与语义正确分别统计。责任／地点建议不进入公司正式结论或正式填出评分。

时间保留原字符串、时区来源和归一值；正文不借发送日期或城市猜时区。系统字段可按声明默认时区解析并标 `assumed`。同事件、范围、用途的可比时间冲突时并列保留，不按来源优先级强选。当前约束和限制以 [时间与原因 ADR](decisions/time-cause-validation.md) 为准。

## 5. 校验、报告与安全

实质引文不匹配或来源不存在仍整单拒绝；关系不完整、用途不符、缺日期／时区只阻止相应正式值，候选保留。低质量／局部覆盖材料明确提示，不掩盖漏读。单次模型可能给出结构完整但含义错误的关系，出处校验不能代替人工业务判断。

报告含工单标识、数据截止时间、七要素、处理过程、恢复验证及待核实事项。告警替代起点不算业务历时，缺确认的可比业务起止仅给限定暂估。报告保留陈述归属，不把供应商说法变成人工确认结论。

真实原文、模型响应、逐单报告和明细只在仓库外 `~/.noc7/`。密钥从环境注入；原图不外发。开发期文本外发沿用已授权闸门，其他服务不因此获准。来源材料中的指令不执行；HTML 转义；本机演示不作为共享生产服务。

## 6. 效果评估与验收

主结果固定按**详情已结单**子集统计；其他状态只单列兼容结果，不混入主要分母。拒绝单保留在分母，区分报告交付率、正式填出、未填／冲突、AI 建议覆盖及语义已知错误。使用含结案结论的输入只能评价交付与复述，不作为独立准确率。

当前已结单结果及与旧基线的描述性对照见 [专项统计](CLOSED_TICKET_REPORT_RESULTS.md)。恢复、起障和原因空值须对照原材料与保存回答，分别记录材料缺少必要信息、含义／来源冲突、模型选择或关系缺失、本地处理限制和整单拒绝。不能把未填一概归因于材料不足或系统漏提。

未来独立验收需要业务标注和来源支持审定，关联事件不得跨集；分别评估语义准确率、可提取事实召回、未知／冲突识别、出处定位、导出结构及附件覆盖。旧草案的拟定百分比目标未获独立验收证明，不作为现有效果。生产性能和模型成本待确定内网服务后实测。
