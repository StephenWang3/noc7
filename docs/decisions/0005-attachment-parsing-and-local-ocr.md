# 0005 附件先本地解析，再输出可定位的保守观测

- 日期：2026-10-27
- 阶段：A2
- 状态：已采纳
- 相关：ARCHITECTURE_OPTIONS §5.2、§6；CONTRACTS；调研 S10 / X01

## 背景

S10 的六类 QoS 统计只存在于截图中；X01 是交付、验收、现场照片与测速拼图，不能按本次故障恢复证据解释。真实 PDF / EML 原件尚未取得。A0 已提供统一工单包、证据定位器、合成附件和外发闸门，A1 同时开发文本链路。

需要保留“读不到”“格式不支持”“只是历史交付材料”的边界。解析器不得读取标准答案来填统计，也不得因为图中提到了某个服务商就定责。

## 可选方案

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 原件全部交给外部多模态服务 | 接口少 | 真实数据禁止外发，难复现，定位未必可靠 |
| 本地 OCR + 文档库 + 确定性结构化 | 无凭据可运行、可定位、方便做基线 | 无统计表曲线和照片只能提示待复核 |
| 曲线像素重建 | 可能补首个非零 | 曲线交叠、压缩和反锯齿易造成伪精度，需要更广的真实样本 |

本地 OCR 比较了当前机器上的 RapidOCR 与 Tesseract，没有完成 PaddleOCR 对照，不能据此声称 RapidOCR 优于所有本地 OCR。

## 选择及理由

1. **沿用 A0，不改共享契约。** `parsers/attachments/` 通过 `PARSERS` 自动注册，只输出 `ParseOutput` / `EvidenceSpan`。不实现 A1 七要素推断，不调用其他解析器。不改 schema、工单包、gold、`gate.py` 或共享 CLI。
2. **默认 RapidOCR。** 唯一新增直接依赖 `rapidocr-onnxruntime>=1.4.4,<2`，同步锁文件。这个分发包含 ONNX 模型，推理时无需下载模型或上传图片。选择旧接口是为了随包携带模型与离线复现；升级需重新验证。保留 Tesseract 作可选基线。安装依赖需要联网，OCR 推理不需要；测试禁止 socket 连接后仍可处理 `real` 分级的运行时合成图片。
3. **先分类，再结构化。** OCR 内容识别 QoS 图、文档拼图、终端截图、带照片标签的照片，其余保留 `other`。分类是启发式，没有标签时不宣称识别了照片。长图分片，重叠区域按文字中心归属去重，坐标回到整张图。
4. **曲线转录可见统计表。** 根据行与列标题读取每类 Max / Avg / Min，校验顺序、百分比范围和缺项，每类输出 `ChartReading` 并引用 OCR 单元与表头。横轴保留原文，不猜时区，不自动纠正 `218` 为 `21.8`，不从 gold 填值。
5. **保留格式原有定位。** PDF 优先文本层；无文本或有栅格图的页补 OCR，像素框换算为未旋转 PDF 坐标 pt，页码从 1 起；文本 PDF 表格用 PyMuPDF 检测。DOCX 保留 0 起段落、表格、行列和整表 `TableReading`。EML 用标准库解 MIME、字符集与传输编码，优先纯文本，区分头、当前消息、引用与签名；HTML 表格结构化，不访问远程资源。
6. **未覆盖的内嵌内容明确报出。** EML 的 PDF / 图片 / 转发邮件附件逐项列出；DOCX 嵌入图片、对象、文本框等标待复核。现有契约只能输出本材料证据，定位器不能表示 MIME 子附件的 PDF 页，故不伪造材料编号或页码。需在导入阶段将内嵌附件登记为独立材料，再用相应解析器。本阶段不改清单，不把邮件附件文件名当路径写盘。
7. **外发要求收紧。** 先调用 A0 `ensure_allowed`，再执行用户“真实工单一律不外发”：即使通用配置有 `approval_ref`，外部提供方也不能处理 `real`。这是收紧通用配置能力，不修改 A0，不把占位批准依据当作用户授权。
8. **提供方可替换。** OCR / 视觉支持本地、按像素哈希匹配的回放、显式启用的 OpenAI 兼容图片 JSON 接口。外部适配器只接受 HTTPS，拒绝重定向，凭据只读环境变量；默认不创建。共享实例串行请求，每 10 次请求完成后间隔 30 秒；429 等 300 秒，默认最多重试一次，失败请求也计数。真实数据在取密钥、编码图片、构造请求前拒绝。
9. **失败与质量可见。** 注册表隔离材料异常；PDF 单页 OCR 失败保留其他页。OCR 分数低于 0.85 标待复核，该阈值未经真实集校准；视觉模型自评高分也不能取消人工复核。嵌入指令只保留为数据并报 `EMBEDDED_INSTRUCTION`。

## 后果与代价

- S10 合成图 6 类、18 个统计值可复现。`first_nonzero` 保持空：基线尚未实现颜色绑定与曲线像素测量，不能硬填 gold 中 BE 的 `02:12`；A4 必须如实评估这个缺口。
- X01 的四个标题区域与验收表可定位；照片设备状态、签字真伪、材料与本次故障的业务关联需人工审核，输出 `needs_review`。
- 真实 PDF / EML 尚未验证；外部适配器仅用模拟 HTTP 验证，未调用 MiniMax 或付费服务，未验证具体供应商兼容性。限流不跨进程共享，多进程部署前需统一调度。
- 本地资源上限：输入 50 MiB、图片 2500 万像素、PDF 100 页、DOCX 解压 100 MiB / 5000 部件、EML 1000 MIME 部件；超限明确失败。这是单机课题边界，不替代上传服务的进程隔离。
- 首轮终端中 EML 的 `\r\n` 曾被误判为字面量换行；逐字节复核确认 P02 为标准 CRLF。正常样本保持 `parsed`；另构造字面量换行样本测试兼容与待复核提示，未修改 A0 的 EML。

参考：[PyMuPDF 页与坐标接口](https://pymupdf.readthedocs.io/en/latest/page.html)、[RapidOCR 官方项目](https://github.com/RapidAI/RapidOCR)、[Tesseract 命令行与 TSV](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage)。使用方式以仓库锁定版本与回归测试为准。
