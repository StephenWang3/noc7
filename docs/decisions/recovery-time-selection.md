# 恢复时间：来源优先与接近取早

状态：已采纳用户确认的取值规则。接近阈值初值为三十分钟，是待业务方确认的暂定值，不是业务方给出的数字。

## 依据与方案取舍

业务方截图明确客户恢复时间、供应商 RFO、联通日志追加的网管恢复时间依次优先，且相差不大时以较早为准。用户选择：全部合格来源接近就取最早，跨度超过阈值才按来源优先；单来源可采用，三类皆无留空；最高优先来源内部超阈值且无明确更正时冲突留空，不降级采用其他来源。

确认前比较过三种组合：全部接近取早、围绕最高优先来源取附近最早、始终来源优先且仅同级取早。采用第一种，规则可以用整组最大跨度解释；代价是一个偏远候选会使整组回到来源优先，而不会仅选择局部接近的子集。

前置修复报告的当前基线是已结单恢复正式填出九／二十二，另有八张来源竞争单未解决，不是九张已填中八张冲突。来源见 [前置修复结果](../RECOVERY_TIME_FIX_RESULTS.md)。

## 来源关系与正式资格

沿用模型一次提取、程序核对出处和结构的分工。`TimeRelation` 兼容追加 `recovery_source`、`recovery_source_basis`、`recovery_round`、`supersedes`、`correction_basis`。来源类别为 `customer`、`vendor_rfo`、`unicom_monitor`、`unknown`；依据是证据编号和原文引文，不按 `attribution`、发送方或字段名补造。

转述按原始陈述方识别。供应商一般进展不自动等于供应商 RFO，RFO 标题不自动证明业务恢复；系统恢复字段来源不明时不兜底。程序验证来源引文可定位、非签名／衍生摘要且无需复核，但无法独立证明模型的来源理解正确。重复和邮件引用可以追溯，不增加独立佐证数量。

仍须通过 `pending_reason` 的本次事件、明确断言、业务恢复用途、可靠材料和完整分钟级时间资格；协议 Up、修复完成、确认动作、日精度或时区未知均留候选。归一和锚点冲突处理沿用 [时间归一决策](recovery-time-normalization.md)，不放宽引文硬校验。

## 裁决顺序与边界

1. 从原始模型有效选中项确定事件／范围／恢复轮次；没有有效选中时，只有一个合格来源组才自动确定目标，多组留空。复算从原始回答确定目标，不因策略最终选中项改变分组。
2. 仅有同组、同来源、指向有效旧候选且有可靠更正引文的明确更正才能排除旧时间。编号规范化同步映射 `supersedes`；缺失、歧义、跨组／来源或循环关系不能静默删除后采用旧时间，保留待核实或冲突。不用邮件先后来推断更正。目标组的更正候选尚不符合时间资格时也留空，不使可能已失效的旧时间重新成为唯一答案。
3. 在 UTC 时间线上比较候选的确切时刻，最大减最小不超过阈值则采用最早值。边界包含相等，秒数计入，相同瞬间按候选编号稳定选择。分钟精度不额外扩张接近阈值。
4. 超过阈值则依次寻找客户、供应商 RFO、联通网管。最高优先来源内部接近时取其中最早值，内部超阈值则冲突留空；低优先来源内部矛盾仍披露，不推翻最高优先来源。
5. 没有合格来源则 `unknown`。自动选择更新 `selected`，保留全部候选及原始模型选择；本规则明确取代此前“不代替模型选择恢复候选”的限制。恢复早于同组业务起点仍撤回，不以低优先来源绕过。来源优先不提升确认等级，客户确认及历时要求不变。

## 配置、审计与兼容

`NOC7_RECOVERY_CLOSE_MINUTES` 接受有限非负分钟数，默认 `30`，零表示只有相同瞬间才接近；非法配置在在线发送前失败。本地 `SemanticAssessment.recovery_selection` 记录实际阈值、暂定标记、目标组、来源、参与及排除候选、跨度、选择和理由。模型提交该记录会被拒绝；最终完整证据校验复算裁决并核对正式值和记录。

阈值随结果冻结，保存结果的回放使用记录值，不受环境后续改变影响。重新解码原始回答则使用当前配置。旧保存结果没有本地裁决记录时按原语义校验，不自动改写；旧原响应重新解码若缺新来源关系，留候选且不猜补来源。

审核报告展示逐候选裁决，公司 HTML 与 Word 共用取值来源、规则理由和“阈值暂定，待业务方确认”说明。`RulesProvider` 继续作为原有规则对照。共享 schema 只追加默认字段，导出 JSON Schema；不改 gate、解析器或历史 gold。责任方／地点规则由另一任务处理，公共文件只追加本任务契约。

## 验证方法

合成边界先冻结，覆盖阈值、优先来源、单来源、来源缺失、同级冲突、明确更正、跨组、时区、用途、模型未选、引用篡改和阈值回放。真实试跑绑定相同二十二张已结单原包和请求证据，每张一次新回答、不自动重试，失败留在分母。

新旧回答之间的前后差异包含模型变化；另将同一新回答按旧冲突策略和新策略禁网重算，分开报告本地规则效果。旧三十一张保存结果另做兼容核验。真实原文、身份、完整响应和逐单报告仅存仓库外 `~/.noc7/`，仓库只提交脱敏汇总，填出不等于准确率。结果见 [恢复取值结果](../RECOVERY_TIME_SELECTION_RESULTS.md)。
